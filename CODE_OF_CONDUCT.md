# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and take feedback kindly, and
focus on what is best for the people using kubed. Harassment of any kind is
not accepted.

To report unacceptable behaviour, use GitHub's **Report a vulnerability**
form on the Security tab (it is private), or contact the maintainer through
their GitHub profile. Reports are kept confidential.
