## The problem

- Kubernetes shows you **status**: `CrashLoopBackOff`, `ImagePullBackOff`, `OOMKilled`.
- Finding the **reason** means `describe`, then events, then logs, across pods.
- Nothing tells you **what changed** before it broke.
- On production, one wrong command in the wrong context is easy to make.

## What kubed does

	<Card title="Apps, not pods" icon="list-format">

## Try it in a minute

<Steps>

1. Install it:

   ```bash
   brew install s3cretagent/tap/kubed
   ```

2. Run it. It uses the same cluster as `kubectl`:

   ```bash
   kubed
   ```

3. Press **enter** on any app to see everything you can do with it. **esc** goes back, **?** shows help.

</Steps>
