## Run it

kubed uses the same kubeconfig and the same current cluster as `kubectl`.

```bash
kubed                          # your current cluster
kubed --readonly               # look around; nothing can be changed
kubed --context staging        # another cluster, by its name or part of it
```

<Aside type="tip">Not sure yet? Start with `kubed --readonly`. You can look at everything, but nothing in the cluster can be changed.</Aside>

## The five keys to know

| Key | What it does |
|---|---|
| **enter** | open a row, or see everything you can do with it |
| **esc** | go back |
| **f** | find anything by name |
| **?** | help |
| **q** | quit |
